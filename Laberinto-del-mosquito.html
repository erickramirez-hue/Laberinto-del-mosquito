Laberinto del mosquito

Escribe un programa con comandos para que el mosquito llegue a la gota de sangre.

Comandos disponibles
AVANZAR
Mueve una casilla hacia donde mira. Si hay pared, chocas.
IZQUIERDA / DERECHA
Gira 90 grados sin moverse.
REPETIR 3 { ... }
Ejecuta el bloque varias veces (ciclo con contador).
MIENTRAS cond { ... }
Repite mientras la condición sea cierta.
SI cond { ... } SINO { ... }
Decide según la condición. El SINO es opcional.
Condiciones
LIBRE (casilla de enfrente libre), PARED, IZQ_LIBRE, DER_LIBRE, META. Antepón NO para negar: MIENTRAS NO META { ... }
